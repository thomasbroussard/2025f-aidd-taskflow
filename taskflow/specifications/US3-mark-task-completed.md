# [Feature] US3: Mark a Task as Completed

**Description:** As a user, I want to mark tasks as complete so that I can see what I have accomplished and focus on remaining tasks.

**Acceptance Criteria:**
- [ ] Each task on the active list has a visible completion checkbox or toggle button.
- [ ] Clicking the toggle updates the UI immediately (e.g., graying out the task or applying a strikethrough).
- [ ] The task's `completed` boolean state is successfully updated in the Firestore backend.
- [ ] Users can un-check a completed task to return it to an active state.
